Agora quero implementar IMPRESSÃO de:

1) Receita médica padronizada
2) Atestado médico

Regras gerais:
- Usar a biblioteca de geração de PDF que o projeto já usa (ex: pdfkit, jsPDF, puppeteer, @react-pdf/renderer etc.). Se não houver nenhuma, sugerir uma compatível com o stack atual.
- Os PDFs devem ser gerados no backend.
- A rota deve retornar um arquivo PDF (content-type application/pdf) ou uma URL temporária, seguindo o padrão do projeto.

1. Receita médica (prescription)
   - Criar uma rota/endpoint:
     - GET /api/medical-encounters/:id/print-prescription
   - Essa rota deve:
     - Carregar o atendimento médico (medical_encounters) e suas prescrições (medical_prescriptions)
     - Carregar dados:
       - Médico (nome, conselho, número do registro ex: CRM)
       - Unidade de saúde (nome, endereço)
       - Paciente (nome, idade, CNS/CPF)
     - Gerar um PDF com layout limpo:
       - Cabeçalho: Prefeitura / Secretaria de Saúde / Unidade
       - Dados do médico
       - Dados do paciente
       - Lista de medicamentos:
         - medicamento – dose – via – frequência – duração – observações
       - Campo de observações gerais
       - Local, data e assinatura do médico (linha para assinatura)

2. Atestado médico
   - Criar uma rota/endpoint:
     - POST /api/medical-encounters/:id/print-medical-certificate
   - Receber no corpo da requisição:
     - tipo (trabalho, escola etc.)
     - data_inicial
     - data_final ou quantidade de dias
     - motivo (opcional)
   - Gerar um PDF com:
     - Cabeçalho institucional
     - Texto padrão, por exemplo:
       "Atesto, para os devidos fins, que o(a) Sr(a). [NOME PACIENTE], [idade] anos, esteve sob meus cuidados profissionais nesta unidade de saúde na data de [data_atendimento] e necessita de [X] dias de afastamento das suas atividades habituais, de [data_inicial] a [data_final]."
     - Local, data de emissão, nome e CRM do médico, espaço para assinatura.
