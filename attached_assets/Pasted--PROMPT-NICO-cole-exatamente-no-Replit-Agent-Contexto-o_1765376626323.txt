2 — Backend: regras e correções cruciais (código a aplicar)
2.1 Forçar respostas JSON (corrige Unexpected token '<')

Criar jsonOnly middleware que detecta Accept header e força respostas JSON em endpoints API; converter handlers para sempre usar res.json(...).

Criar errorHandler global (exemplo em TS):

// middlewares/errorHandler.ts
import { Request, Response, NextFunction } from "express";

export function errorHandler(err: any, req: Request, res: Response, next: NextFunction) {
  console.error(err);
  const status = err.status || 500;
  res.status(status).json({
    error: err.message || "Erro interno",
    code: err.code || "INTERNAL_ERROR",
    details: process.env.NODE_ENV === "production" ? undefined : err.stack
  });
}


Em app.ts, sempre app.use(express.json()) e app.use(errorHandler) no final.
