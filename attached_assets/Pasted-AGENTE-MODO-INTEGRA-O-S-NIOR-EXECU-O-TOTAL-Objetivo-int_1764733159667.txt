AGENTE, MODO: INTEGRAÇÃO SÊNIOR / EXECUÇÃO TOTAL

Objetivo: integrar ao SaaS existente (não alterar esquemas e features já em produção) um módulo que permita criação/edição/validação/encaminhamento de **fichas SINAN** idênticas aos templates oficiais (BPA/APAC e demais formulários SINAN) e que obrigue preenchimento completo antes de permitir avanço para o setor responsável; enviar alertas para fiscalização/epidemiologia em casos graves; exportar remessas de dados e preparar o arquivo para digitação no SINAN (setor de digitação), garantindo zero duplicações.

REGRAS GLOBAIS:
1. **Não alterar tabelas existentes** do SaaS sem flag explícita "migrate_schema: true". Se campos extras forem necessários para auditoria/attachments, armazene em tabelas auxiliares namespaced (ex.: `tfd_documents`, `sinan_documents`) e não sobrescreva dados de produção.
2. **Multi-tenant**: respeitar `enforceUnitScope()` e roles existentes. Novos endpoints herdam segurança atual.
3. **Audit trail obrigatório** para cada geração/edição/assinatura. Registrar (userId, unitId, templateVersion, timestamp, ip).
4. **Detecção de duplicações**: implementar check por identidade do paciente (CPF/CNS/NAME+DOB+municipio) + hash do caso + dedupe fuzzy; não bloquear automaticamente, apenas sinalizar e sugerir merge ao gestor.
5. **Pixel-perfect**: usar PDF template original (uploaded OR fetched), mapear coordenadas por templateVersion e permitir calibração via UI.
6. **Se o site oficial estiver disponível**, faça download automático dos templates e MANUAL oficial do SINAN; se inacessível, usar PDFs já anexados.

PASSOS AUTOMÁTICOS A EXECUTAR (ordem):
A. SCOPE & DISCOVERY
   A1. Detecte todos os templates em `/templates` (pdf) e no link oficial `http://vigilancia.saude.mg.gov.br/...sinan/`. Se o site retornar erro, logue e continue com PDFs enviados.
   A2. Para cada template PDF, extraia texto e imagem (pdf->png para UI) e gere um `template manifest` JSON com campos detectados (OCR+heurística de labels).
   A3. Compare campos detectados com o mapeamento padrão SINAN (se disponível no manual). Marque campos obrigatórios.

B. MAPEAMENTO (non-destructive)
   B1. Crie um mapeador `mapEntityToTemplate(unitId, entity)` que aceita registros atuais do SaaS (`tfd_requests`, `citizens`, `tfd_trips`, etc.) e produz o payload para o template.
   B2. Não modifique entidades; ao faltar dados, o payload aponta campos faltantes e retorna erro de validação.

C. UI / UX
   C1. Adicionar nova área no SaaS: **Notificações / SINAN** com sub-views:
       - Preencher ficha (visual: fundo PNG do template + inputs posicionados)
       - Validador (lista de campos obrigatórios e warnings)
       - Calibração de template (drag/drop caixas para campos -> salva `templates/<name>.json`)
       - Fila por setor (triagem → aprovação → digitação)
   C2. Ao salvar, persistir rascunho em `sinan_drafts` (tabela nova) com `unitId`, `createdBy`, `templateVersion`.
   C3. Botões: `Salvar rascunho`, `Validar e Enviar ao Setor`, `Gerar PDF Oficial`, `Gerar Arquivo para Digitação (TXT/CSV)`.
   C4. UI forçada: só habilitar "Enviar ao Setor" se `validations.allRequiredTrue == true`.

D. BACKEND / API
   D1. Novos endpoints (todos com enforceUnitScope()):
       - POST `/api/sinan/templates/refresh` -> atualiza templates do repositório oficial (ou usa /templates) 
       - GET `/api/sinan/templates` -> lista templates e versions
       - POST `/api/sinan/drafts` -> cria rascunho (payload JSON)
       - GET `/api/sinan/drafts/:id` -> obter rascunho
       - PATCH `/api/sinan/drafts/:id` -> atualizar rascunho
       - POST `/api/sinan/drafts/:id/validate` -> valida e retorna lista de faltantes/warnings
       - POST `/api/sinan/drafts/:id/send` -> valida + grava documento final e cria entry para o setor destino (queue)
       - GET `/api/sinan/queue?unitId=` -> listar fichas aguardando revisão por setor
       - POST `/api/sinan/:id/generate-pdf` -> gera PDF preenchido (usa pdf-lib)
       - POST `/api/sinan/:id/generate-txt` -> gera arquivo no layout SINAN/SIA (use layout definitions)
       - POST `/api/sinan/:id/approve` & `/reject` -> ações do setor responsável, com observações
   D2. Jobs assíncronos:
       - `job.sanitize_and_merge_duplicates` (daily)
       - `job.alert_severe_cases` (real-time webhook on save/send)
       - `job.generate_remessa_periodica` (monthly)

E. VALIDAÇÕES E REGRAS (detalhadas)
   E1. Validations.set = {
     requiredByTemplate: true,
     formatValidators: {
       CPF: regex+mod11,
       CNS: regex+CNScheck,
       IBGE: 6 digits,
       date: AAAAMMDD or ISO,
       CID: /^[A-Z]\d{2}(\.\d{1,2})?$/
     },
     mutualExclusivity: { CPF xor CNS }, // conforme manual BPA
     conditionalRequired: {
        if procedure in SIGTAP_requires_APAC => require APAC fields (diagnostic, justification)
     }
   }
   E2. Business rules:
     - Only allow send-to-digitacao if `status == approved` and `validations.passed == true`.
     - Auto-assign sector target based on disease code / procedure (configurable mapping).
     - If `urgency == emergencia` or disease in `notifiableCriticalList`, trigger immediate alert: push notification + SMS/email + webhooks to EPID.
   E3. Duplicate detection:
     - Primary check: exact match on (CPF/CNS) + date onset +/- 3 days + disease code
     - Secondary fuzzy: name similarity (Levenshtein < 0.2 normalized) + DOB + municipality
     - On match: create `possibleDuplicate` cluster; allow operator to `merge` or `ignore`.

F. GERAÇÃO PDF (pixel-perfect)
   F1. Use `pdf-lib` (Node) to load original PDF template, embed font (if template font not standard embed TTF), and draw text at coordinates from `templates/<name>.json`. Save as new PDF.
   F2. Provide preview endpoint that returns an image of final PDF page (for UI).
   F3. For signature: allow insertion of scanned signature image or PAdES signing (option).

G. GERAÇÃO REMESSA / EXPORT TXT
   G1. Implement generator conforming to `Layout_Exportacao_BPA.pdf` (padding, zeros, CRLF, checksum described).
   G2. Export options: `SIA/BPA layout`, `SINAN CSV` (fields mapping). Include validation mode to run before export.
