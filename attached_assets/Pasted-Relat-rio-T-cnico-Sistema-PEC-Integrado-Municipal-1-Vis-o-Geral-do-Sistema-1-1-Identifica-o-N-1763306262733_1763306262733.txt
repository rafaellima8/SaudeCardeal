Relatório Técnico - Sistema PEC Integrado Municipal

1. Visão Geral do Sistema

1.1 Identificação

Nome: PEC Integrado Municipal - Sistema de Gestão de Saúde
Município: Cardeal da Silva
Versão: 1.0.0
Data do Relatório: Janeiro 2025
1.2 Objetivo

Sistema integrado para gestão completa da atenção básica de saúde municipal, abrangendo desde o cadastro de cidadãos até relatórios gerenciais, em conformidade com os padrões do e-SUS APS.

2. Arquitetura Técnica

2.1 Stack Tecnológico

Frontend:

React 18+ com TypeScript
Vite (build tool)
TanStack Query v5 (gerenciamento de estado servidor)
Wouter (roteamento)
shadcn/ui + Tailwind CSS (interface)
Recharts (visualização de dados)
Backend:

Node.js com Express
TypeScript
Drizzle ORM
PostgreSQL (banco de dados)
Infraestrutura:

Replit (hospedagem e deploy)
Porta 5000 (desenvolvimento e produção)
2.2 Arquitetura em Camadas

┌─────────────────────────────────────┐
│     Camada de Apresentação          │
│   (React + shadcn/ui Components)    │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│     Camada de Aplicação             │
│   (TanStack Query + API Routes)     │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│     Camada de Negócio               │
│   (Express Routes + Storage Layer)  │
└─────────────────────────────────────┘
              ↓
┌─────────────────────────────────────┐
│     Camada de Dados                 │
│   (Drizzle ORM + PostgreSQL)        │
└─────────────────────────────────────┘

13. Fluxos de Trabalho Principais

13.1 Fluxo de Atendimento

Recepção: Paciente chega e recebe senha na fila
Triagem: Enfermeiro registra sinais vitais e queixa
Consulta: Médico realiza anamnese e exame físico
Prescrição: Sistema registra medicamentos prescritos
Farmácia: Dispensação de medicamentos
Exames: Solicitação se necessário
Acompanhamento: Agendamento de retorno
13.2 Fluxo TFD

Solicitação: Profissional registra necessidade de TFD
Aprovação: Gestor analisa e aprova
Agendamento: Data de viagem definida
Transporte: Tipo de transporte e acompanhante
Conclusão: Registro do retorno
13.3 Fluxo de Estoque

Entrada: Registro de lote com validade
Controle: Monitoramento de estoque mínimo
Dispensação: Vinculada a prescrição médica
Alertas: Notificação de estoque baixo ou vencimento
