2.3 Como preencher campos que não existem no seu modelo

Você afirmou que não quer modificar o esquema. Em alguns casos pode faltar authorizationNumber ou procedureSecondary[]. Para isso:

Use campos deriváveis temporários (no payload JSON) sem adicionar colunas (recommended) — ou

Adicione campos opcionais na tabela tfd_requests somente se desejar persistir autorização e histórico (recomendado para rastreabilidade).

Mas a geração do PDF pode acontecer sem persistir todos os campos — basta montar o JSON com dados agregados antes de gerar o PDF.

4) Implementação técnica (recomendada — usa o template original sem alterar o PDF)
4.1 Abordagem recomendada: fundo PDF + pdf-lib (Node)

Serve para gerar PDFs idênticos ao visual original.

Fluxo: carregar PDF template → desenhar textos nas coordenadas → salvar.

Biblioteca: pdf-lib (Node). Alternativa: pdfrw/PyPDF2 (Python) ou borb para geração mais avançada.

Exemplo (outline) — gerar BPA-I (Node + pdf-lib)

(esse código é esqueleto — coordenadas precisam calibrar):

import fs from "fs";
import { PDFDocument, StandardFonts } from "pdf-lib";

export async function generateBpaIPdf(payload) {
  const templateBytes = fs.readFileSync("./templates/Formulario_BPA_I.pdf"); // :contentReference[oaicite:7]{index=7}
  const pdfDoc = await PDFDocument.load(templateBytes);
  const font = await pdfDoc.embedFont(StandardFonts.Helvetica);
  const page = pdfDoc.getPage(0);

  // Mapeamento de coordenadas (exemplos)
  page.drawText(payload.cns || "", { x: 75, y: 900, size: 10, font });
  page.drawText(payload.nomePaciente || "", { x: 75, y: 880, size: 10, font });
  page.drawText(payload.dataNascimento || "", { x: 520, y: 880, size: 10, font });
  // ... resto dos campos

  const pdfBytes = await pdfDoc.save();
  return pdfBytes; // enviar como application/pdf
}


Calibração: você precisa de um tooling para calibrar (veja seção 5).

11) Trecho de código adicional: endpoint express para gerar e salvar PDF
// routes/pdf.js (Express)
import express from "express";
import { generateBpaIPdf } from "../lib/pdfGenerators.js";
import { enforceUnitScope } from "../middleware/auth.js";
import fs from "fs";
import path from "path";

const router = express.Router();

router.post("/tfd/requests/:id/generate/bpa-i", enforceUnitScope(), async (req, res) => {
  const reqId = req.params.id;
  // buscar dados no DB (use seu service)
  const tfdRequest = await services.tfdRequests.findById(reqId, { include: ["citizen","originUnit","trip"] });
  if (!tfdRequest) return res.status(404).send({ error: "Not found" });

  // montar payload com mapeamento
  const payload = mapRequestToBpaPayload(tfdRequest); // implemente essa função conforme tabela acima

  // gerar pdf bytes
  const pdfBytes = await generateBpaIPdf(payload);

  // salvar em storage / attachments (path por unit)
  const unitId = tfdRequest.originUnitId;
  const filename = `BPAI_${reqId}_${Date.now()}.pdf`;
  const savePath = path.join("/storage", unitId, filename);
  fs.mkdirSync(path.dirname(savePath), { recursive: true });
  fs.writeFileSync(savePath, pdfBytes);

  // registrar auditoria (quem, quando, templateVersion)
  await services.documents.create({ tfdRequestId: reqId, path: savePath, createdBy: req.user.id });

  res.download(savePath);
});

export default router;
